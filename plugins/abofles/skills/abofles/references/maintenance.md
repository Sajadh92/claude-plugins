# Commands and maintenance

Read when the user asks what a command does, or when editing the plugin.

- `/abofles:route <task>` — dry run: prints the `main:` line, every route line and the estimated units, spawns nothing. Use it to check a plan before paying for it.
- `/abofles:bill [--all]` — spawns per model and side, verdicts, top topics, the unit cost index, and the real spend (tokens, $, $ saved vs the main-session model). Reads the ledger the hook writes to `~/.abofles/ledgers/`.
- `/abofles:init [--dry-run]` — scans the project and adds a `## abofles overrides` block to its `CLAUDE.md`, with at most 5 suggested lines.
- `/abofles:status [--all] [--resolve <id>] [--unresolve <id>] [--session <sid>] [--trace <text>]` — session summary from the ledger: spawns per model as bars, confidence, open follow-ups. `--resolve <id>` closes one once handled, `--unresolve <id>` reopens it; `--trace` writes a "by hand" line in the memo Journal.
- `/abofles:agents [auto | N | off | ask]` — show or set the agent gate: this task's budget, how many ran, the auto table.
- `/abofles:guide [--all]` — the 🧭 next line (what to do now, by priority), or the whole ladder.
- `/abofles:memo [path]` — writes the Now section of the work memo (`.claude/abofles-memo.md`) so the session can be compacted or paused without losing the thread. The context watch points here.
- `/abofles:resume [--all] [--resolve <n> [note]] [--reopen <n>] [--trace] [--note <text>]` — "where was I?": prints the resume block from the memo without re-reading anything; `--resolve` ticks a Needs-you item, `--reopen` turns it back, `--trace` leaves a "by hand" Journal line, `--note` records a decision made in chat.

Topics, tiers, cell overrides, reply caps and signals live in one place: `scripts/gen_matrix.py` (plugin root). Edit it, run `python3 scripts/gen_matrix.py`; it rewrites the topic index in `references/topics.md` and `references/matrix.md`. Never edit the index or the matrix by hand. Reply formats live in `agents/*.md` (plugin root), one file per side. Hooks live in `hooks/abofles_hook.py` (`pre` blocks and enforces the agent budget, `post` logs and checks sync replies or writes a `pending` line for background spawns, `stop` fills that line on `SubagentStop`, `guard` warns on direct-read streaks, `start` writes the session marker and the resume block, `receipt` refuses a stop without the receipt and journals it, `prompt` notes the effort and the break, `decision` logs questions and the gate answer, `qgate` guards questions, `sendmsg` unlocks the re-ask after a `SendMessage` to the Judge/Explainer; the CLI mode `tokens` prints the context size); the memo and gate CLIs in `scripts/memo.py` and `scripts/agents.py`; the status in `scripts/status.py`; the output style in `output-styles/receipt.md`; unit tests in `scripts/test_hooks.py`; the bill in `scripts/bill.py`; commands in `commands/*.md`.
