# Agent gate

Read before the first Agent call of a session.

**Agent gate — once per session, before the first spawn.** The `PreToolUse` hook denies the first Agent call of a session until you have asked it (unless the override says `Agents = auto | N | off`). Size the task first (Step 2: tier, topics, files; Small = T1–T2 one topic → 1–2 agents; Medium = T3 or two topics → 3–4; Large = T4, 3+ topics or 20+ files → 5–8 with parallel reads). Then ask **one** `AskUserQuestion` whose question text contains `Abo Fles agent gate`, options in this order, labels starting exactly like this:
1. `Auto (recommended)` — description: *abofles sizes every task by topic, side and tier (Orchestrator: Minor 2 · Normal 3 · Sensitive 7 · Critical 12 agents; Worker: 1 · 2 · 5 · 8); no more questions this session; an over-budget spawn raises the budget itself (twice per task, `Budget raise = auto`).*
2. `This task: N agents` — N and the plan from your route lines, with `≈ <units> u · ≈ $<est>` (estimate $ from the session's average tokens per spawn in the ledger, else 300K tokens at list price); asked again next task.
3. `Main session only` — 0 agents this task. In Orchestrator mode add *(costly: <Model> does every read itself)*.
4. Orchestrator mode, Large task only: `Max: N agents · M parallel`. Worker mode (any tier): `Switch main to Opus 5.5 and orchestrate` — if chosen, reply with one line, `Pick Opus 5.5 in the model picker (bottom right), then send "go".`, and **end the turn** (the plugin cannot switch the model).
The user may type a number or `off` in Other. The hook records the answer (budget, `auto`, or `off`) and tells you `agents: …` — continue the task; never re-ask. A per-task answer expires at the receipt and the gate asks again at the next task's first spawn; `Auto` and `off` hold for the session. `/abofles:agents <auto | N | off | ask>` changes it; when the user says "agents N" in chat, run `bash "<plugin root>/scripts/py" "<plugin root>/scripts/agents.py" set N --session "${CLAUDE_SESSION_ID}"`. Over an **auto** budget (the gate's `Auto`, or `Agents = auto`) with `Budget raise = auto` (the default), the hook raises the budget instead of denying: by half the tier's budget, at least 2, at most twice per task (Minor 2 → 4 → 6, Sensitive 7 → 11 → 15), and adds `abofles: budget raised N → M (auto, raise k/2)` — carry on, no question. Over a fixed budget (`Agents = N`, a `This task: N` answer), with `Budget raise = ask`, or after the second raise, the hook denies the spawn: finish in the main session or ask the user to raise it (that one AskUserQuestion, within 10 min of the deny, needs no Judge) (answering the gate again — `Auto`, a number — restarts the count from that moment). Judge and Explainer spawns never count. A prompt without the `abofles: <Topic> / <Side> · T<n>` first line has no tier: the budget is sized as 🟡 Normal and the hook says so. Background spawns are capped at `Parallel` running at once (default 3).

Main-session effort lookup, last resort: the desktop `mcp__ccd_session_mgmt__get_session` tool with `"self"` (load it with ToolSearch).
